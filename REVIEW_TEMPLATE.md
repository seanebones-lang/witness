# Proof A review template

Copy this template into a GitHub issue, discussion, pull request, or a separate review document. Remove identifying information if you prefer not to be named.

```markdown
## Witness / Humanity Grid Proof A review

**Review lane:** computational chemistry | research software | provenance and archives | security | AI evaluation | other

**Reviewer identity and relevant expertise:**
Optional. State any conflict of interest.

**Exact material reviewed:**
- Witness commit/tag:
- Humanity Grid commit/tag:
- Date reviewed:
- Operating system and relevant tool versions:

### Steps performed
List commands, inspection steps, and any substitutions.

### Result
- [ ] Reproduced as documented
- [ ] Partly reproduced
- [ ] Could not reproduce
- [ ] Inspection only; no replay attempted

### Findings
For each finding, state the claim or file, observed behavior, expected behavior, evidence, severity, and whether another person could reproduce it.

### Claim-boundary assessment
Are the stated claims too broad, too narrow, or accurate? Explain.

### Proof B requirements
What would you require before calling a next experiment scientifically useful?

### Disposition
**confirmed finding | unconfirmed finding | opinion/proposal | no finding**

### Publication preference
- [ ] May be attributed by name
- [ ] Publish without my name
- [ ] Do not publish; retain only an internal contact record
```
