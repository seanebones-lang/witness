# Decision records

This directory is the durable public record of material Witness decisions. It
contains acceptances, deferrals, and refusals; it is not a record of consensus.

Use the [decision-record template](../../.github/DECISION_RECORD_TEMPLATE.md)
for schema, cryptography, protocol, privacy, moderation, ranking, trust-model,
and material domain decisions. A refusal of a material domain, privacy, or
security objection must link the objection, rejected alternative, relevant
constitutional article, date, and any minority report. If no separate minority
report was submitted, say so explicitly.

Decision records do not establish independent review, endorsement, deployment
approval, or fitness for high-consequence use.
