# Minority reports

This directory preserves dissent that remains material after a Witness decision.
It is a shelf for disagreement, not an endorsement list and not a substitute
for an appeal by a person affected by a deployment.

Each report should identify its decision record or issue, the author's stated
perspective and provenance status, the concrete objection, any safer
alternative, and limits. Reports may be anonymous or pseudonymous where that
is safer; the repository must not claim independent review or endorsement unless
identity, independence, scope, and publication permission are established.

A maintainer who rejects a material domain, privacy, or security objection links
this report, or an explicit statement that no separate minority report was
submitted, from the decision record. A report remains linkable even if the
associated issue is closed or later evidence changes the decision.

Do not include personal data, confidential evidence, credentials, or sensitive
security details here. Use the private routes in [SECURITY.md](../../SECURITY.md)
when public publication could create harm.
