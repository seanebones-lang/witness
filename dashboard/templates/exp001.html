INFERRED

Consensus Inference

Claim: The two independent Vina replicates (seeds 101, 202) produce correlated docking scores (r = 0.885) exceeding the consensus threshold (r ≥ 0.80), indicating reproducible binding affinity predictions for six known CDK2 inhibitors.

Premises: 12 observed docking measurements (6 compounds × 2 replicates), each from independent AutoDock Vina runs with different random seeds but identical binding-site parameters.

Methodology: Pearson correlation between replicate score vectors. Outlier detection via IQR on per-compound absolute differences.

Uncertainty: ±0.115 (bootstrap 95% CI on correlation coefficient)

Falsifiers (What Would Change This Conclusion)

Pending
Third replicate falsification: A third independent Vina replicate with a different seed produces docking scores that correlate with the first two at r < 0.80.
Pending
Experimental contradiction: Wet-lab binding assays (ITC, SPR) for the six compounds contradict the predicted rank order from consensus docking scores.
Completed-Falsified
Incorrect center falsification: Using the earlier incorrect binding-site center yields r < 0.80 or reversed rank order — already observed in the failed attempt.

Reproduce Locally

Prerequisites

# Humanity Grid
cd ~/Desktop/humanity-grid
# Requires: AutoDock Vina 1.2.5, Python 3.10+, openbabel, rdkit

# Witness
cd ~/Witness
cargo build --release --bin witness-ingestion
cargo run --release --bin witness-api
# Dashboard at http://127.0.0.1:8080/experiments/EXP-001

Run EXP-001

# From humanity-grid root
python validation/run_vina_replicate.py --pdb 1KE7 --center -9.11,48.31,11.80 --seed 101 --output validation/output/results/rep1
python validation/run_vina_replicate.py --pdb 1KE7 --center -9.11,48.31,11.80 --seed 202 --output validation/output/results/rep2
python validation/consensus.py --rep1 validation/output/results/rep1 --rep2 validation/output/results/rep2

Ingest into Witness

# Using the ingestion CLI (requires valid CIDs matching payload)
witness-ingestion jsonl --file exp001_observed.jsonl
witness-ingestion infer --file exp001_inferred.json
witness-ingestion generate --file exp001_generated.json
