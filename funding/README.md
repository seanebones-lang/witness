# Witness + Humanity Grid Funding Readiness Packet

**Status:** preparation material; no application, award, partnership, independent review, customer commitment, or funding is implied.

This packet turns the existing Proof A demonstration into a bounded funding case: an independently designed and reviewed Proof B. It is written for research collaborators, open-science organizations, mission-aligned funders, and later non-dilutive funding programs.

## Non-negotiable statement

Proof A demonstrates preserved local computational artifacts and a replayable Grid-to-Witness record path. It does **not** demonstrate a drug candidate, biological activity, docking accuracy, independent execution, external validation, scientific discovery, adoption, or a deployed volunteer-computing network.

Every proposal, conversation, budget, and progress report must retain that boundary.
