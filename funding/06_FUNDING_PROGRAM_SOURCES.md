# Funding-program source register

This register records program information used in the Funding Readiness Packet. Verify each program’s live requirements before any application. A program’s listing here is not an eligibility finding or recommendation to apply.

| Program | Current source and use |
| --- | --- |
| NSF SBIR/STTR | [NSF America’s Seed Fund](https://seedfund.nsf.gov/our-program/) describes non-dilutive Phase I and Phase II R&D funding. [Project Pitch instructions](https://seedfund.nsf.gov/apply/project-pitch-information/) define the current suitability test, four pitch sections, character limits, and submission constraints. |
| NSF PESOSE | [NSF 26-506 solicitation](https://www.nsf.gov/funding/opportunities/pesose-pathways-enable-secure-open-source-ecosystems/nsf26-506/solicitation) states the March 2, 2027 deadline, Tracks 1–3, award limits, eligibility categories, and review criteria. |
| NSF CSSI | [CSSI program page](https://www.nsf.gov/funding/opportunities/cssi-cyberinfrastructure-systems-scientific-innovation) currently says it is waiting for a new publication. It is a future partner-led route, not an active application claim. |
| NLnet | [NLnet funding page](https://nlnet.nl/funding.html) describes €5,000–€50,000 grants and general open-source conditions. [NLnet’s current application page](https://nlnet.nl/propose/) lists the November 3, 2026 deadline and requires disclosure of any generative-AI assistance. |

## Application discipline

- Do not submit AI-written text to NLnet without complying with its current disclosure and prompt/log requirements.
- Do not submit an NSF Project Pitch until its customer, market-pull, technical-risk, team, and defensibility assertions can be supported.
- Do not represent the project as eligible, invited, applied, selected, or funded before the applicable program confirms that state.
- Store an exact final application copy and all submitted attachments in a dated, access-controlled record before submission.
