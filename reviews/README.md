# Submitted Reviews

This directory preserves substantive reviews and project responses. A review is
not an endorsement. Publication here does not establish the reviewer's identity,
independence, credentials, or agreement with later project decisions.

Each review must state its provenance status:

- **independent-verified:** reviewer identity or stable pseudonym, independence,
  scope, and permission to publish are established;
- **independent-pseudonymous:** stable pseudonym, independence, scope, and
  permission are established without public civil identity;
- **owner-supplied-unverified:** the project owner supplied the material, but
  authorship, independence, or publication permission has not been established;
- **maintainer-review:** authored by a project maintainer.

Only reviews with established independence count toward the roadmap's independent
review gate. Material objections remain useful regardless of status.
