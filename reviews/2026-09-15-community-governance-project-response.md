# Project response: community-governance review

**Date:** 2026-09-15

## Accepted changes

`CONTRIBUTING.md` now distinguishes a short review note from a full change proposal. It provides an affected-person concern form, a durable minority-report directory, a decision-record directory, and a rule that material domain, privacy, and security refusals receive a public decision record. It explicitly states one decision maker, no review quorum, non-endorsement, and material generative-tool disclosure with human responsibility.

## Limits that remain

This does not create an appeal body, independent reviewer quorum, confidential case-management channel, shared stewardship, or safe deployment process for person-concerning records. No actual minority report or refusal is fabricated to demonstrate the process. This supplied review remains owner-supplied-unverified.
